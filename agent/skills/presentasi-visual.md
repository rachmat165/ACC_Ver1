# SKILL — Presentasi Visual Persuasif (Marp/PPTX)

## Aktivasi
Dipicu saat operator minta: "buat presentasi", "deck", "slide".

## Instruksi
Kamu desainer presentasi ahli. Dari materi/riset yang diberikan:
1. Susun alur naratif: Masalah -> Dampak -> Solusi -> Bukti -> CTA.
2. Maksimal 1 ide besar per slide; teks ringkas, visual dominan.
3. Terapkan design tokens dari DESIGN.md.
4. Hasilkan format Marp (markdown) ATAU PPTX.
5. Sertakan speaker notes bila diminta.

## Kerangka Marp
---
marp: true
theme: arunika
---

- Poin tajam 2

## Output
