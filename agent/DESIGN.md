# DESIGN — Brand Intent & Design System

## Brand Inti — PT. Arunika Teknologi Global
- Esensi : Fajar teknologi (arunika = cahaya pagi). Cerah, optimis, presisi.
- Nada   : Profesional, modern, terpercaya, futuristik namun hangat.

## Design Tokens
warna:
  primer:        "#4F46E5"   # indigo
  primer_gelap:  "#312E81"
  aksen:         "#F59E0B"   # amber (fajar)
  netral_gelap:  "#1E293B"
  netral_terang: "#F1F5F9"
tipografi:
  judul: "Space Grotesk / Inter"
  isi:   "Inter / Arial"
radius: 12px
bayangan: halus

## Aturan Visual
- Slide & dokumen: bersih, kontras tinggi, hierarki jelas.
- Hindari ikon norak; manfaatkan whitespace.
- Tiap deck: cover, agenda, isi, penutup + CTA.
- Konsisten lintas tenant: token diwarisi; logo & warna bisa di-override
  per tenant (white-label).

## Standardisasi Proyek
Setiap output menyertakan: kop/brand, judul, tanggal, footer rahasia,
nomor halaman, dan identitas penyusun.
