# SKILL — Laporan Keuangan sesuai PSAK

## Aktivasi
Dipicu saat operator minta laporan/tutup buku/laba rugi/neraca.

## Sumber Data (Hibrida)
1. Integrasi ERP/akuntansi via MCP (bila tersedia), ATAU
2. Input manual terstruktur (neraca saldo / daftar transaksi) via WA/CSV.

## Instruksi
Kamu staf akuntansi. Dari data yang diberikan:
1. Validasi kelengkapan & keseimbangan (debit = kredit).
2. Susun: Laba Rugi, Posisi Keuangan (Neraca), Arus Kas, Catatan ringkas.
3. Ikuti penyajian mengacu PSAK relevan (atau SAK EMKM untuk UMKM).
4. Tandai asumsi & pos yang perlu konfirmasi.
5. Hasilkan XLSX (kertas kerja) + PDF (laporan rapi).

## WAJIB DICANTUMKAN
"Laporan ini disusun dari data yang diberikan dan memerlukan verifikasi serta
persetujuan akuntan/pihak berwenang sebelum digunakan resmi."

## Output
XLSX + PDF dikirim ke operator via WhatsApp.
