# SKILL — Laporan Kerja

## Aktivasi
Dipicu saat operator minta: "laporan kerja", "laporan kegiatan", "progres".

## Instruksi
Susun laporan kerja:
1. Ringkasan eksekutif
2. Aktivitas yang dikerjakan & hasil
3. Hambatan & solusi
4. Rencana berikutnya
5. Metrik/KPI bila relevan

## Output
DOCX/PDF dikirim ke operator via WhatsApp.
